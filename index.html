    คำถามที่พบบ่อย

    Purple Cloud Studio คืออะไร?

    สตูดิโอเล็ก ๆ ของฉันเอง ทำเกมแนว HTML ที่เปิดเล่นบนเบราว์เซอร์ได้ทันที และเกมบน Roblox รวมถึงงานด้านวิศวกรรมอุตสาหการและการผลิตอัจฉริยะ

    เล่นเกมได้ที่ไหน?

    เกม HTML เปิดเล่นได้จากลิงก์ในหน้ารายละเอียดของแต่ละผลงาน ส่วนเกม Roblox ค้นชื่อเกมในแอป Roblox ได้เลย

    ใช้เครื่องมืออะไรสร้างเกม?

    HTML / CSS / JavaScript สำหรับเกมเว็บ, Roblox Studio และ Luau สำหรับเกม Roblox, สไปรต์ชีตที่วาดเอง และ AI เป็นผู้ช่วยในการพัฒนา

    ติดต่อร่วมงานหรือให้ฟีดแบ็กได้อย่างไร?

    ทักมาได้ที่เพจ Facebook "Purple Cloud Studio" ยินดีรับทุกคอมเมนต์และไอเดียเกมใหม่ ๆ
